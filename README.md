# FoodBridge AI — Zero Hunger

A beginner portfolio demo built with Streamlit, pandas, and scikit-learn.

## Deploy
- Upload `app.py` and `requirements.txt` to a GitHub repository.
- Open https://share.streamlit.io, connect GitHub, and deploy the repository with `app.py` as the main file.

## Important limitations
- The machine-learning priority prediction is trained on artificial practice data. It is not a food-safety assessment.
- This version keeps donation rows in the current Streamlit browser session only. Download the CSV to keep a copy. Add a persistent database/storage service before using real donations.
- Do not enter private or sensitive information in a public demo.
